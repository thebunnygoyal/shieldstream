# Demo script (2 to 3 minutes, every step real)
1. Open the app on a phone-sized window. Say what it does in one line.
2. Create a request: "Design sprint", 0.01 TAZ. Show the code in the memo and the QR.
3. Say what is shielded: amount and memo are encrypted, the explorer shows only that a shielded tx exists.
4. Tap "Pay with demo wallet (testnet)". Say clearly it is a demo wallet sending a real shielded testnet payment.
5. Watch the timeline: waiting, seen, mined and confirmed. Show the confirmed screen, block height and the explorer link.
6. State limits: testnet only, demo payer is capped, QR not tested with third-party wallets, single process.
